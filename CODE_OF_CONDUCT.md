# Code of Conduct

Be direct, be kind, argue with evidence. Critique code and claims, never people. Assume good faith, verify before accusing, and keep discussion about the work.

Maintainers may remove comments, issues, or contributions that are abusive, harassing, or off-topic, and may block repeat offenders. If you experience or witness unacceptable behaviour, contact the maintainer via their GitHub profile.

This is a small project's working agreement — short on purpose. It exists so the issue tracker stays a place where bugs get fixed.
